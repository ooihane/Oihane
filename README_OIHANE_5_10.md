# Oihane 5.10 — Home compacto y agenda priorizada

## Cambios
- **Home sin el cuadro superior:** se elimina la imagen/banner que ocupaba espacio al entrar.
- **Una sola agenda antes de los módulos:** primero aparecen tareas pendientes, planes y eventos de hoy y mañana; después, una línea divisoria y otros elementos agendados o tareas de importancia alta.
- **Menos desplazamiento:** la agenda se presenta en un único bloque compacto, de modo que los módulos quedan más arriba.
- **Iconos ilustrados y a todo color:** los 13 módulos tienen ilustraciones SVG originales, con formas, detalles y una paleta cálida de azules, verdes, terracotas, malvas y amarillos. No son emojis ni simples iconos lineales.
- Los datos existentes siguen guardándose con las mismas claves locales.
- Caché del service worker actualizada a `oihane-v20`; versión de interfaz 5.10.

## Actualizar
1. Descarga una copia JSON desde **Más → Descargar copia JSON**.
2. Descomprime el ZIP y sustituye los archivos de la raíz del repositorio GitHub Pages.
3. Publica los cambios y abre Oihane con conexión para que se descargue la versión nueva.
