# Oihane 5.11 — Agenda unificada, búsqueda de precios y apertura superior

## Cambios
- **Home:** en «Hoy y mañana» ya no se muestran etiquetas de tipo «Tarea», «Plan» o «Evento». Todos los elementos aparecen en una única agenda; solo se conserva información secundaria útil, como la hora o la ubicación.
- **Idealo:** ahora puedes corregir o acortar la consulta antes de buscar, lo que permite añadir marca/modelo o eliminar palabras que empeoren los resultados. La búsqueda abre Idealo España con la consulta codificada correctamente. La opción 3 también abre resultados de Google limitados a Idealo como alternativa cuando el buscador interno no encuentra bien el producto.
- **Apertura de módulos:** al entrar en cualquier módulo, la página vuelve explícitamente al inicio, evitando que se conserve la posición de desplazamiento anterior.
- Versión de interfaz `5.11.0`; caché del service worker `oihane-v21`.

## Actualizar
1. Descarga una copia JSON desde **Más → Descargar copia JSON**.
2. Descomprime este ZIP y sustituye los archivos de la raíz del repositorio GitHub Pages.
3. Publica los cambios y abre Oihane con conexión para que se descargue la versión nueva.
