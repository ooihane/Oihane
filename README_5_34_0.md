# Oihane 5.34.0 — Voz configurable

- Botón ⚙ junto al control de voz del asistente para consultar las voces españolas realmente devueltas por Safari.
- Reproducir prueba, guardar voz o restaurar selección automática. La preferencia se almacena localmente, nunca se presupone que Mónica exista en el dispositivo.
- Selección preferente de la voz guardada; alternativa española si desaparece.
- Reintento con otra voz solo para errores de síntesis recuperables; nunca para cancelaciones.
- Se elimina la envoltura de voz heredada de 5.33.0.
- Nueva versión de caché de PWA para actualizar la instalación.

Limitación: Safari iOS controla las voces disponibles y puede impedir audio automático fuera de una interacción del usuario. Es imprescindible comprobar selección y reproducción en el iPhone real.
