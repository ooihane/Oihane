# Oihane 5.14 — cabeceras pictóricas y papeles pintados

- Se eliminó el icono que aparecía junto al nombre en la cabecera de cada módulo.
- Las cabeceras pictóricas se redujeron aproximadamente a la mitad de su altura.
- Las imágenes se mantienen inspiradas en los artistas favoritos: Monet, Caspar David Friedrich, Manet, Van Gogh, Artemisia Gentileschi, Miguel Ángel y Sorolla.
- Cada módulo tiene un motivo de fondo tipo papel pintado distinto, con paletas coordinadas y discretas.
- El fondo de Home incorpora una textura cálida de lino/jacquard botánico y geometría suave.
- Versión de interfaz 5.14.0; caché del service worker `oihane-v24`.
- Cambios visuales; no se modifican las claves ni los datos guardados.

Para actualizar, conserva primero una copia JSON desde Más → Descargar copia JSON y sustituye los archivos del repositorio por los de este ZIP.
