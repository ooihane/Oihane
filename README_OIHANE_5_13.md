# Oihane 5.13 — Home compacto

## Cambios
- La agenda de Home se puede plegar y desplegar con un botón.
- Por defecto se muestra plegada para que los módulos queden más arriba y el Home sea más compacto, especialmente en móvil.
- Al plegar se conserva un resumen con el número de elementos de hoy/mañana y los prioritarios.
- La preferencia se guarda localmente en `oihane_home_agenda_collapsed`; no modifica ni elimina tareas, planes o eventos.
- Versión `5.13.0`; caché del service worker `oihane-v23`.

## Actualizar
1. Descarga una copia JSON desde Más → Descargar copia JSON.
2. Sustituye los archivos de la raíz del repositorio por los de este ZIP.
3. Publica los cambios y abre Oihane con conexión para descargar la versión nueva.

La sintaxis de JavaScript y el ZIP deben validarse antes de publicar. No se ha probado la aplicación publicada directamente en iPhone.
