# Oihane 5.8 — tareas importantes y compra mejorada

## Cambios funcionales
- **Inicio / Home:** muestra un bloque de tareas importantes pendientes (importancia alta), con fecha y acceso al módulo Tareas. Se puede completar una tarea directamente desde Home; las tareas recurrentes mantienen su siguiente repetición.
- **Borrar productos de compra:** el botón de borrar elimina el producto de forma global, tanto de General como de su lista de tienda, evitando que reaparezca en otra lista.
- **Categorías automáticas:** se amplía el vocabulario de alimentos y productos domésticos para reconocer más artículos de despensa, congelados, limpieza e higiene. La clasificación se recalcula también para los productos ya guardados al cargar la aplicación.
- Versión de aplicación 5.8.0; caché del service worker actualizada a `oihane-v18`.

## Actualización
1. Descarga primero una copia desde **Más → Descargar copia JSON**.
2. Descomprime el ZIP y copia todos los archivos a la raíz del repositorio GitHub Pages, sustituyendo los anteriores.
3. Publica los cambios y abre Oihane con conexión para que se actualice la caché.

Los datos guardados se mantienen en el almacenamiento existente; esta actualización no borra las listas ni el resto de módulos.
